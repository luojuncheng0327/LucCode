# LucCode

A personal AI agent with memory and soul.

This is an **early-access** build published ahead of the 1.0 launch. It
installs a `luc` command that reports its version and the release plan.
The full CLI — local agent server, chat, and data tooling — arrives on
this same package name with the 1.0 release:

```
npm update -g luccode
```

Until then, the package intentionally stays small.
